Piano Player

A simple browser based piano player that lets you play piano notes using your computer keyboard.

##Features

Play piano notes using keyboard keys

White keys use letters like A S D F G H J K L

Black keys use W E T Y U O P

Shows the current chord/note

AI Declaration

I used AI assistance during the development of this project, particularly for parts of the JavaScript interaction logic.

AI helped me with the logic for:

Selecting piano keys and matching them with their corresponding keyboard key codes

Connecting keyboard keydown events to correct piano audio using data key attributes...
I reviewed, tested, and modified the AI assisted code while developing the project and integrated the final implementation myself.
AI mostly used for learning new logic
